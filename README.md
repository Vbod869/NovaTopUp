# NovaTopup — HTML, CSS, JavaScript

## Cara menjalankan
1. Ekstrak ZIP.
2. Pastikan `index.html`, `style.css`, dan `script.js` berada di folder yang sama.
3. Buka `index.html` di browser, atau jalankan dengan extension Live Server di VS Code.

## Fitur
- Tampilan responsive untuk desktop, tablet, dan HP.
- Katalog 9 game dan paket nominal.
- Cari paket, filter game, keranjang, ubah jumlah dan hapus item.
- Metode pembayaran tampilan QRIS, DANA, GoPay, OVO, dan transfer bank.
- Form detail pemesanan, kode demo, biaya layanan, kode promo NOVA10.
- Riwayat pesanan tersimpan di localStorage browser.
- Toggle dark/light mode.
- Menu navigasi mobile.

## Catatan penting
Ini frontend demo murni HTML/CSS/JS. Pesanan hanya disimpan pada browser yang digunakan. Metode pembayaran tidak mengirim uang, tidak membuat QR pembayaran asli, tidak mengonfirmasi status transaksi ke bank, dan tidak mengirim item game. Untuk benar-benar menerima pembayaran dan mengirim item, perlu integrasi backend/server, payment gateway resmi, serta API supplier game resmi. Jangan meminta atau menyimpan password akun game.
